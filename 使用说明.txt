============================================
    烽火南境小说生成器 - 使用说明
============================================

【启动方式】

方式1：双击运行 "启动小说生成器(推荐).bat"
    - 会自动检测Python环境和依赖包
    - 如果缺少依赖会自动尝试安装
    - 推荐使用此方式

方式2：双击运行 "启动小说生成器.bat"
    - 直接启动，不做环境检测
    - 如果环境配置正确，启动更快

方式3：命令行启动
    - 打开命令提示符或PowerShell
    - 进入项目目录: cd "d:\小说\烽火南境\小说生成器"
    - 运行: python "烽火南境 .py"

【环境要求】

1. Python 3.8 或更高版本
   下载地址: https://www.python.org/downloads/

2. 必要的Python包:
   - tkinter (通常随Python自带)
   - Pillow (图片处理)
   - requests (网络请求)
   - scikit-learn (可选，用于文本分析)
   - tkinterdnd2 (可选，用于拖拽功能)

   安装命令:
   pip install Pillow requests scikit-learn tkinterdnd2 -i https://pypi.tuna.tsinghua.edu.cn/simple

【项目结构】

- 烽火南境 .py          : 主程序文件
- 启动小说生成器.bat    : 快速启动脚本
- 启动小说生成器(推荐).bat : 带环境检测的启动脚本
- books/                : 书籍数据目录
- chapters/             : 章节文件目录
- database/             : 数据库目录
- extracted_content/    : 提取内容目录
- *.py                  : 各种功能模块

【注意事项】

1. 首次运行可能需要安装依赖包，请保持网络连接
2. 如果使用API功能，需要配置API密钥
3. 建议定期备份books目录中的重要数据
4. 程序运行时会生成一些缓存文件，属于正常现象

【常见问题】

Q: 提示"未检测到Python安装"
A: 请安装Python 3.8或更高版本，并确保添加到系统PATH

Q: 提示缺少某个模块
A: 使用pip安装对应模块，或使用"启动小说生成器(推荐).bat"自动安装

Q: 程序闪退
A: 尝试使用命令行启动，查看具体错误信息

【技术支持】

如有问题，请查看程序日志或联系开发者。
